# Color Palette

## Primary Colors

| Color | Hex | Usage |
|-------|-----|-------|
| Orange | `#FE7F2D` | Primary accent, CTAs, highlights |
| Black | `#000000` | Text, backgrounds, strong contrast |
| Dark Blue | `#233D4D` | Secondary accent, headers |
| Light Gray | `#EAECF0` | Backgrounds, borders, subtle elements |

## Current Brand Color (Legacy)
- Maroon: `#421D24` - Previously used in buttons and accents

## Tailwind Classes
```tailwind
bg-[#FE7F2D]    /* Orange background */
text-[#FE7F2D]  /* Orange text */

bg-[#000000]    /* Black background */
text-[#000000]  /* Black text */

bg-[#233D4D]    /* Dark blue background */
text-[#233D4D]  /* Dark blue text */

bg-[#EAECF0]    /* Light gray background */
text-[#EAECF0]  /* Light gray text */
```

## Implementation Notes
- Use `#FE7F2D` for primary CTAs and interactive elements
- Use `#000000` for bold text and strong visual emphasis
- Use `#233D4D` for secondary headers and accents
- Use `#EAECF0` for subtle borders and backgrounds
- Maintain `#421D24` for existing elements during transition
